# ADR-0002: Python-Referenzprototyp mit Standardbibliothek

**Status:** akzeptiert (Vorschlag zur späteren Portierung unbestätigt)

**Entscheidung:** `reference/python/` nur mit stdlib + `unittest`, damit Tests ohne Installation laufen. Der Prototyp definiert Event-Schema, Regelformat und Testvektoren für die spätere Produktiv-Engine.
